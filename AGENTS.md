# HAMUTUK 2.0 Project Rules

- Use JavaScript only. No TypeScript or TSX.
- Follow the existing React + Vite + Tailwind v4 frontend and Express + MySQL backend.
- Inspect the workspace before editing files.
- Do not replace working features without explaining why.
- Do not put server secrets in frontend files.
- Do not create public self-registration.
- Distinguish local-only reports from server-acknowledged reports.
- Use stable client-generated IDs and idempotent report sync.
- Clearly label demo data and simulated SiteWatch telemetry.
- Never infer the cause of a missing heartbeat without evidence.
- Preserve Tetum-first UI and usable mobile layouts.
- Keep official-warning publishing restricted to authorised users.
- Do not claim tests passed unless they were actually run.
- Run npm build and relevant API checks after implementation.
- Update README.md with actual setup and tested behaviour.
